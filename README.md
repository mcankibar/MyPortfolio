# 🎨 Portfolio Website Project

This repository contains a fully functional **Portfolio Website** developed using **ASP.NET Core 9 MVC**, **Entity Framework Core**, and **Bootstrap**. The project serves as a personal showcase site, allowing an admin to manage content dynamically through an admin panel with full **CRUD operations** and **ViewComponent** usage.

## 🚀 Features

- **Responsive Design**: Optimized for all screen sizes using **Bootstrap**.
- **Admin Panel**: Manage website content including projects, skills, and contact messages.
- **CRUD Operations**: Full create, read, update, and delete functionality for all entities.
- **ViewComponents**: Modular and reusable UI components (e.g., recent projects, contact form).
